# Build notes - Weight-Space Programming whitepaper

The whitepaper is a 24-page A4 PDF typeset in LaTeX and compiled with **Tectonic**.

## Files

| File | Purpose |
|---|---|
| `main.tex` | Full LaTeX source (body; no title page - the cover is merged separately) |
| `references.bib` | 44-entry bibliography (no invented entries; pending items flagged in Appendix C of the PDF) |
| `figures/` | 13 vector PDF figures, generated by `scripts/make_figures.py` (matplotlib) |
| `scripts/make_figures.py` | Regenerates every figure deterministically |
| `cover.html` | The title-page source (rendered to PDF and merged as page 1) |
| `print.html` | Standalone HTML print-CSS fallback (open in any browser → Ctrl+P → PDF) |
| `weight-space-programming.pdf` | The final, merged whitepaper |

## Build command

```bash
# 1. Regenerate the figures (optional - they are committed)
python3 scripts/make_figures.py

# 2. Compile the body (two passes resolve cross-references and the bibliography)
tectonic main.tex
tectonic main.tex

# 3. Render the cover (Playwright, 794px = A4 at 96dpi)
node $PDF_SKILL_DIR/scripts/html2poster.js cover.html --output cover.pdf --width 794px

# 4. Merge cover as page 0 and stamp metadata (see merge.py, or:)
python3 - <<'EOF'
from pypdf import PdfReader, PdfWriter
w = PdfWriter()
c = PdfReader("cover.pdf").pages[0]; c.scale_to(595.28, 841.89); w.add_page(c)
for p in PdfReader("main.pdf").pages: w.add_page(p)
w.add_metadata({"/Title": "Weight-Space Programming: An Independent Field Guide",
                "/Author": "Het Patel (Hunterdii)",
                "/Subject": "An independent, badge-honest explainer of Weight-Space Programming",
                "/Keywords": "weight-space programming, model editing, interpretability, LLM"})
with open("weight-space-programming.pdf", "wb") as f: w.write(f)
EOF
```

The interactive companion site (`../site/`) embeds this PDF at `/whitepaper.pdf` - regenerate
that copy after rebuilding the whitepaper.
